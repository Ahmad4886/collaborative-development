# Collaborative Development Using GitHub

## Project Overview
This project demonstrates collaborative software development using Git and GitHub. Developers work on separate branches, commit changes, submit Pull Requests, review code, and merge approved changes into the main branch.

## Project Feature
The project introduces a student profile page containing student information and academic details.

## Technologies
- Git
- GitHub
- HTML
- CSS
- Markdown

## Development Workflow
1. Create a feature branch.
2. Implement the required feature.
3. Commit the changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Request a teammate's review.
7. Address feedback and merge approved changes.

## Learning Objectives
- Understand Git branching.
- Practice collaborative development.
- Learn Pull Request reviews.
- Resolve feedback and merge changes safely.
